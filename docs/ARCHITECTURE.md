# 架构说明

插件入口 `src/addon.lua.in` 注册本地生命周期与渲染回调。`tools/build.py` 把模块、预设及兼容配置组合为单个 Core Lua 资源；运行时不依赖源码目录。

| 模块 | 职责 |
| --- | --- |
| `layout.lua`、`target_data.lua`、`memory.lua` | 固定构建的只读实体、姿态、目标与生命周期快照 |
| `replication_probe.lua` | 分离读取网络镜像阶段，用于识别远端已投出 G60 |
| `observation_scope.lua` | 当前主世界视角周围 80 米的三维源位置筛选 |
| `enemy_reader.lua` | 有限预算内采集敌军候选，验证存活、实体代际与当前姿态 |
| `target_estimator.lua` | 队友 G60 的本地估算、持续重评及切换稳定时间 |
| `controller.lua` | 统一生命周期、目标验证、绘制列表和白／红状态 |
| `projection.lua`、`camera_selector.lua`、`screen_renderer.lua` | 当前相机的完整视口投影、裁剪与屏幕 GUI 提交 |
| `marker_shapes.lua`、`geometry.lua` | 准星、位置圆圈、估算外圈与线条几何 |
| `scene_light.lua`、`bloom_marker.lua`、`glow_renderer.lua` | 本插件独立场景光源、自发光标记及清理 |
| `preset_options.lua` | 目标、颜色、发光预设选择 |
| `renderer.lua`、`world_gui_renderer.lua` | 渲染适配与保留的世界 GUI 路径 |

## 目标路径

自己的 G60 使用已有真实目标字段，保持原有标记。队友目标字段在本机不一定完整可用，因此仅对确认非本机拥有、已投出且仍存活的远端 G60 做估算。未知归属和无效源位置不会被强行解释为锁定。

候选源于本机已发现的敌军实体，当前目录包含 123 个资源身份，每次最多读取 96 个敌人。扫描约 5 Hz，候选搜索半径为距 G60 200 米；源 G60 的显示半径仍为距当前视角 80 米。这两个范围分别控制候选发现和源显示。

追踪评分使用运动方向、距离变化、敌人相对速度与优先级。不明确时仍根据近期朝向、距离和优先级重新排序；新候选连续更合适约 0.3 秒后切换，等待时继续画原连线。相同分数优先保留当前目标，并使用实体身份稳定排序。当前与待切换候选均优先进入下一轮有限预算刷新。

候选池暂时过期时保留目标身份，但终点仍逐帧读取、验证死亡与实体代际，不沿用旧坐标。没有可验证目标时不制造终点。源爆炸状态按实体代际锁存，避免爆炸后被残留选敌重新点亮。

## 显示

所有估算目标样式都有同色外圈，默认半径 32 像素，大于 40×40 方框的外接圆；世界十字近距离放大时外圈随投影扩展。目标样式与四种颜色的预设共用这套逻辑。

线条是本地屏幕覆盖层；发光标记与点光源为本插件创建的场景对象，受游戏曝光、Bloom 和场景遮挡影响。G60 本体模型、材质及游戏全局后处理保持原样。白／红光点反映当前是否存在可显示的真实或估算目标，不能证明队友的真实锁定；目标外圈用于区分估算。

停止插件、离开任务、读取失败或对象结束时清理本插件创建的显示与场景对象。模块不写入原版选敌、网络对象、导航、伤害或爆炸状态。
